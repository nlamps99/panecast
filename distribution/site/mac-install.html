Mac 安装与打开说明

适用于 macOS 13 及以上、Apple Silicon（M 系列芯片）。

拖入应用程序

  1. 打开下载的 DMG 安装包。
  2. 把 Panecast.app 拖到旁边的 Applications（应用程序） 文件夹。
  3. 从「应用程序」打开 Panecast。升级前先退出旧版，替换应用会保留账号和配对。

出现「移到废纸篓」或「无法验证开发者」

当前预览版使用本地签名，尚未经过 Apple 公证。请先尝试「系统设置 → 隐私与安全性 → Panecast → 仍要打开」。

如果仍打不开，且安装包来自 Panecast 官方下载页，可按下面步骤处理：

  1. 按 ⌘ Command + 空格，输入「终端」或 Terminal，按回车。
  2. 确认 Panecast 已移入「应用程序」，复制下面的三行命令。
  3. 在终端按 ⌘V 粘贴，再按回车。
打开已安装的 Panecast
codesign --verify --deep --strict "/Applications/Panecast.app" &&
xattr -dr com.apple.quarantine "/Applications/Panecast.app" &&
open "/Applications/Panecast.app"

这会先校验签名完整性，再仅清除 Panecast 的下载隔离标记并打开应用。若校验失败，请重新下载。若系统明确报告恶意软件或「将损坏你的电脑」，请停止运行并联系开发者，不要执行该命令。

也可以用一条命令安装

安装器会下载官方版本、核对 SHA-256 和签名完整性，安装到「应用程序」，并处理这份预览版的隔离标记。无需 sudo；没有系统应用目录写权限时，会安装到你的个人「应用程序」目录。

安装或升级桌面客户端
curl -fsSL https://ningzx.cn/panecast/install-desktop.sh | bash

返回官方下载页 · 正式消除首次打开提示，需要 Developer ID 签名与 Apple 公证。
