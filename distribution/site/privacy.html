Panecast 隐私政策

更新日期：2026 年 11 月 9 日

Panecast 是一个开源终端远程客户端，用于在手机、平板和桌面客户端上连接你配置的电脑。当前 iOS 客户端通过 Panecast relay 与 Mac 上的 cmux 通信。项目代码：https://github.com/nlamps99/panecast。

连接与数据处理

Panecast 会向你配置的 relay 或中转服务器发送配对信息、随机生成的客户端标识、设备名称、操作指令和连接状态，并接收终端内容、工作区信息和通知。发送这些数据是完成连接、远程输入和显示终端所必需的。

你可以直连电脑，也可以自行部署或选择中转服务器。局域网连接可能使用未加密的 HTTP / WebSocket；跨网络的中转连接可使用 HTTPS / WSS。中转连接不是端到端加密，服务器运营者能够读取其转发的终端内容、输入和图片。请只连接你信任的电脑与服务器，并了解所选服务的隐私政策。账号页面提供项目服务器的默认地址，你可以改为自己的服务器。只有在主动登录、注册或配对时才会建立相应服务连接。

账号

账号为可选功能。注册和登录时，用户名、密码和客户端名称通过 HTTPS 发往所选服务器。服务器保存用户名、经 scrypt 处理的密码摘要、登录令牌哈希及你授权的电脑绑定关系，不保存明文密码或配对码。每个登录会话有效期为 30 天；修改密码会撤销其他设备的会话。「账号与电脑」中可以解除电脑绑定、退出登录或验证密码后删除账号。删除账号同时删除该服务器的账号、会话与绑定关系，不会删除电脑文件、运行中的程序或其他独立配对。账号属于所选服务器，不自动跨服务器合并。

保存在设备上的信息

  • 配对凭据、设备标识和已配对电脑的信息保存在系统安全存储中。iOS 上的配对凭据使用仅限本设备的 Keychain 可访问级别。
  • 账号令牌同样保存在系统安全存储中。Mac 桌面端使用系统钥匙串保护加密密钥，在应用数据目录保存加密凭据文件。退出账号会清理本机该账号的凭据和对应输入记录。
  • 终端显示偏好、通知偏好和已接收的收件箱记录保存在本机应用存储中。
  • 命令草稿、最近发送的输入和收藏的常用输入也保存在本机，按电脑分别管理。你可以删除单条记录或清除最近输入；移除电脑时会清理其输入记录。
  • 应用运行时在内存中保留显示所需的终端画面和历史片段。
  • 最近访问、置顶工作区、通知规则和快捷键配置保存在本机。恢复阅读位置使用终端行的上下文哈希和位置，不在使用记录里保存对应终端正文。
  • 主动预览的项目文件会从已连接电脑传到手机；保存或分享时会生成本机缓存文件。通过系统分享菜单另存到其他位置的副本，由你选择的应用或存储服务管理。

你可以在应用中移除已配对的电脑、清空通知记录，或卸载应用以删除应用的普通本地数据。移除独立配对的电脑只解除当前客户端的配对；从账号解除绑定会撤销该账号所有设备对此电脑的账号访问。独立配对的服务器记录不会自动删除；服务器上的凭据和数据需要由相应运营者管理。iOS Keychain 的保留行为由系统管理，卸载应用不保证删除全部安全存储项。

相机、照片和剪贴板

应用在你使用相应功能时申请相机或照片权限，用于扫码配对、拍照或选择要发送的图片。你选择发送的图片会传输到已连接的电脑，并可能经过你配置的中转服务器。应用也会在你主动使用复制或粘贴功能时读写剪贴板。

通知

允许通知后，应用可向你配对的 relay 或中转服务器登记 Apple 推送令牌。接收后台通知还要求 relay 已配置 Apple Push Notification service（APNs）。推送通知会经过 Apple，远程推送使用通用提示及工作区、终端和电脑标识，不包含终端输出；本机通知和稍后提醒可能显示任务标题和通知内容。你可以在 iOS 系统设置中关闭通知或调整锁屏预览。新版中转服务器可以把推送登记转给电脑，原始令牌保存在电脑，服务器仅保存令牌哈希。旧版本服务器或未配置 APNs 的电脑可能无法提供后台推送。新版 relay 会在电脑上保留最近 2,000 条通知与明确的任务状态事件，用于手机断线后补齐。这份记录可能包含任务通知内容，普通终端画面和逐字聊天输出不会因此写入事件日志。你设置的项目静音、免打扰时区及提醒规则会发送给已配对的电脑，以便一致地控制后台推送。

分析与第三方服务

本版本未集成广告、跨应用追踪或开发者自建的行为分析服务。开发者不会因你使用本应用而自动收到终端内容。你自行配置的电脑、中转服务器和网络服务可能保留运行日志；其处理方式由相应运营者决定。

如果你使用 TestFlight，Apple 可能按其条款提供测试反馈、使用信息和崩溃报告。通过 TestFlight 或 GitHub 主动提交的反馈可能包含你提供的诊断信息。发送反馈前，请移除终端中的密码、令牌、配对二维码及其他敏感内容。

演示模式

离线演示使用设备本地生成的虚构项目、终端输出和通知，不连接你的真实电脑，也不向 relay 或中转服务器发送演示操作。

反馈与政策更新

一般问题和隐私咨询可通过项目的GitHub Issues 联系维护者。公开问题中请勿包含私人信息。安全漏洞请按Security Policy通过 GitHub 私密漏洞报告提交。

本政策会随功能和数据处理方式的变化更新，最新版本发布于本页面。
