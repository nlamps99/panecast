02 / GET CONNECTED

装好以后，三步连接。

01

配置这台电脑

panecast setup

填写管理员分配的中转地址、电脑 ID 和连接密钥，选择允许访问的来源。

02

启动后台网关

panecast start

后台运行，登录后自动启动。tmux 任务在 tmux new -s work 中开始。

03

手机扫码配对

panecast pair

输入这台电脑的配对码，再用手机 App 扫描终端里显示的二维码。

↳

目前通过邀请接入中转，每台电脑使用独立凭据。安装器方式在当前终端可使用 ~/.local/bin/panecast；新终端中直接运行 panecast。

↳

桌面版打开「账号登录与电脑管理」，注册或登录账号，再粘贴目标电脑的配对链接。之后在另一台设备登录同一账号，即可取回电脑列表。账号属于所填写的服务器；不同服务器分别管理账号。目标电脑需保持网关运行。已发布的 Android build 13 仍使用扫码配对，账号入口将在新手机构建中提供。

Homebrew 升级

brew upgrade panecast/tap/panecast
升级或卸载会影响配对吗？

配置和配对数据保存在 ~/.cmuxremote/，升级和卸载软件时保留。升级后运行 panecast restart。

Homebrew 用户先运行 panecast stop，再运行 brew uninstall panecast。独立安装器用户重新运行安装命令即可升级；卸载时运行：

curl -fsSL https://ningzx.cn/panecast/install.sh | bash -s -- --uninstall

npm 用户使用本页最新的 npm 安装命令升级，卸载使用 npm uninstall -g panecast-cli。

cmux 和 Codex 怎么连接？

tmux 可直接由网关访问；cmux 需要本地 Swift relay 提供接口。Codex 可授权为只读历史，或按实际服务配置启用会话控制。每个来源都在电脑端单独授权，安装网关不会自动授权全部来源。

panecast sources list 查看来源；panecast desktop prepare 准备实验性的桌面桥接。

需要一直开着电脑吗？

需要。网关运行在你的电脑上，Mac 关机或休眠时手机无法操作终端。公网模式下，手机和 Mac 都主动连接中转服务器；配置局域网后，同一可信 Wi-Fi 下可以自动直连。
