# 桌面附件与会话活动状态

## 已确认的根因

截图中的 Claude 终端在任务结束后执行过历史压缩。真实记录包含 `compact_boundary`
和带 `isCompactSummary: true` 的 user 记录；网关把所有带文本的 user 记录都视为
开始新任务，所以摘要之后没有新任务也会显示“正在处理”。按截图时间截取记录能复现
`active: true`，无需猜测终端标题或用超时隐藏指示器。

桌面输入只连接了相册选图，没有消费浏览器的文件 drop 和图片 paste 事件。
统一网关的 `relay.info` 又没有返回选中来源的上传限制，客户端只能按旧版中转的
小帧限制处理附件。

## 修改

- Claude 活动状态按记录语义更新：压缩摘要和元数据不会开始新任务，真实新提问仍会。
  摘要内容继续可读，缓存和后续刷新会带回修正后的状态。
- Tauri 把拖放交给 WebKit 的 HTML 文件 API。终端和对话区域接收文件拖入，普通输入框
  与展开编辑接收剪贴板图片；附件按钮可选择多个任意类型文件。仅读取用户通过系统
  拖放、粘贴或选择器交给页面的 File，没有增加任意本地路径读取接口。
- 附件依次上传，保留文件名、MIME 和原始字节。超出连接大小限制的图片使用已有图片
  压缩流程并改为 JPEG 文件名；普通文件超限时明确报错。纯文本粘贴保持默认行为。
- 上传后将带 shell 引号的远端路径插入当前光标位置，等待用户发送。展开编辑也显示
  上传进度。路由在读取文件前固定，切换终端后不继续上传剩余文件；已上传路径归属
  原终端草稿。上传过程中不会提交缺少附件路径的输入。
- `relay.info` 按选中来源读取实际上传限制，并受网关消息上限约束。新客户端仍兼容
  缺少该能力的旧网关；连接失败和授权撤销会正常显示原错误。

离线/只读入口、取消读取、目标切换和超限图片压缩。TypeScript 和 ESLint 检查通过。
DOM 测试使用 jsdom，不控制用户的浏览器或窗口。

网关在 macOS arm64 的隔离环境中运行完整测试：93 项，92 项通过；按原设置跳过
1 项会操作真实 Codex 任务的测试。新增用例覆盖已结束任务的压缩摘要、元数据、
无变化缓存、新任务恢复，以及选中来源的上传限制与授权撤销。

桌面原生传输、凭据存储、打包 CSP 测试和 Clippy 通过。桌面发布版本为 0.2.3，
网关包为 0.1.3；目标电脑已有未提交工作，部署时只合并本任务对应的网关补丁，
不替换整个 checkout 或私有配置。
