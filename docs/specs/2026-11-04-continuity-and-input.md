# 连续使用、输入和多电脑

这轮改动让手机在中断、切换和重新打开后能继续之前的工作，并为长提示词和宽屏增加操作入口。

## 会话与阅读恢复

每台电脑分别保存最近访问的 30 个终端、上次工作区窗口、置顶工作区及最后打开的终端或
来源会话。重新打开 App 时恢复上次的终端／来源页；从通知明确指定的页面进入时，通知优先。
切换电脑会恢复它各自的终端选择。最近访问的入口会先确认终端仍存在，已关闭的条目会移除。

上滑阅读时保存逻辑行的上下文哈希与位置，不把终端正文写入使用记录。重开终端时在
保留的历史中查找该锚点，最多读取 24 页；无法找到时说明历史已不在恢复范围内。
切换到其他终端或主动回到最新输出会取消正在进行的恢复。来源的授权检查仍由电脑端执行。

## 输入与快捷键

命令输入框的展开入口打开全屏编辑器。回车换行，支持选中多行增加／减少缩进，保存返回，
或点击独立发送按钮。输入法仍在组字时不会提交或改写文本；发送失败保留草稿，结果未知
时提示先检查远端。草稿最长 64,000 字符，超出后明确提示，不会静默截断当前编辑。

快捷键支持通用、AI 任务、tmux 配置，可复制、改名、添加、移除和排序。每台电脑有默认
配置，每个工作区可覆盖。`Ctrl + ↑` 始终可用；还可选择 `Shift + Tab`、`Ctrl + R`、
功能键等。横向滑动快捷键栏不会误发按键，长按需要重复的方向键仍可连续发送。
移除电脑时清除其配置关联，用户创建的命名配置保留。

## 终端显示

自动折行适合日志和文字输出，原始列宽适合表格及 TUI，可左右滑动。切换只改变手机上的
显示，不调整电脑终端大小。字号仍可双指缩放。设置里可选择默认显示方式。

当窗口宽度至少 850 pt 且较短边至少 600 pt 时，默认并排显示工作区侧栏与终端。
侧栏可搜索、切换窗口、置顶工作区，并显示待处理数量；窗口变窄时自动收起。
可在终端设置中关闭宽屏侧栏。

## 通知与服务器

离线补消息、明确状态事件、项目静音、免打扰和重复合并见
[通知补齐说明](2026-11-04-notification-recovery.md)。需要新版 relay；旧服务保持在线通知兼容。

一个 broker 现在可配置多个 relay。配置、独立凭据和迁移说明见
[broker README](../../broker/README.md)。手机的配对协议保持不变，连接诊断按对应电脑鉴权
查询健康状态，公开健康检查不返回其他电脑的信息。

## 弱网验证

broker 集成测试启动独立 tmux 服务器、本地 broker 和故障代理，使用真实客户端的
RelayConnection、TerminalSession、AutoChannel 检查：

- 断线及 relay 重启后的通知补齐、明确完成事件。
- 丢失文字或回车响应时不自动重发命令，避免重复执行。
- 前台唤醒及 Wi-Fi／蜂窝网络变化时切换 LAN／broker。
- 多电脑和多手机之间的推送偏好、撤销与连接隔离。
- 屏幕增量帧出现序号缺口时重新订阅完整画面。

端到端 Apple 投递和锁屏系统行为仍需要 TestFlight 真机验收。测试入口为
手机「设置 → 通知 → 发送测试推送」。服务端新增能力需升级对应 broker／relay，
手机新增的原生输入接口需要重新构建，不能只更新 JavaScript。
